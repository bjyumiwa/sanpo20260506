# 元加治ゆる巡礼ポイントアプリ（静的HTML版）

この版は npm 不要です。GitHubに `index.html` を置くだけで動きます。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作る
2. このフォルダの `index.html` をアップロードする
3. リポジトリの `Settings` を開く
4. `Pages` を開く
5. `Build and deployment` の Source を `Deploy from a branch` にする
6. Branch を `main`、folder を `/root` にして Save
7. 1〜2分後に表示されるURLを開く

## 白紙になる場合

- ファイル名が `index.html` になっているか確認
- GitHub Pages の公開元が `main / root` になっているか確認
- ブラウザを更新
