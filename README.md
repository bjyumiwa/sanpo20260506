# 元加治ゆる巡礼ポイントアプリ

元加治駅から約8000歩の散歩コースを、ポイントがたまる小さなWebアプリにしたものです。

## 使い方

```bash
npm install
npm run dev
```

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作る
2. このフォルダの中身をアップロードする
3. 次を実行する

```bash
npm install
npm run build
npm run deploy
```

または、GitHubの画面から `Settings` → `Pages` で公開設定をします。
